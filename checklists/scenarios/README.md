# Scenario checklists

Generated by `checklists/build_scenario_checklists.py` and deployed through Mandi.

| Checklist | Mandi code | ODK project | Establishment filter | Matching establishments |
| --- | --- | --- | --- | --- |
| Pharmacy Scenario A | `scenario_pharmacy_a` | 1 — Mandi inspections | `kind = 'pharmacy'` | 956 |
| Pharmacy Scenario B | `scenario_pharmacy_b` | 1 — Mandi inspections | `kind = 'pharmacy'` | 956 |
| Pharmacy Grade 2 Scenario | `scenario_pharmacy_grade_2` | 1 — Mandi inspections | `kind = 'pharmacy' and grade = '2'` | 651 |
| Factory Scenario | `scenario_factory` | 4 — آمریت فابریکات | `kind = 'factory'` | 79 |

The two pharmacy forms share the same structure but have distinct checklist codes and
titles. The grade-2 form treats “category 2” as the Licensing pharmacy grade
(`grade = '2'`); the Licensing `pharmacy_type` is also `2` for the same 651 records.

Regenerate the workbooks with:

```bash
.venv/bin/python checklists/build_scenario_checklists.py
```

Each XLSForm filters ODK's `establishments` Entity List with a `choice_filter` on the
`establishment_id` question. Mandi links the project’s Entity List during deployment.
